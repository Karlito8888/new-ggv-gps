### 🟠 Majeurs

- **RLS Supabase non vérifiable depuis le repo** (`src/lib/supabase.ts`) — la clé anon est publique par design (bundlée), le risque réel est que la sécurité data repose entièrement sur RLS + GRANTs Postgres. Confirmer RLS ON sur toutes les tables, révoquer les droits directs de `anon` sauf les 2 RPC (`get_blocks`, `get_lots_by_block`), fixer `search_path` sur les fonctions `SECURITY DEFINER`.
- **`src/components/WelcomeOverlay.tsx:51`** — fetch RPC `get_lots_by_block` sans annulation → `setState` possible après démontage (avertissement React + risque d'écraser un état plus récent lors d'un changement de bloc rapide). _(corrigé après doc)_ — **Nuance d'implémentation** : l'API d'annulation supabase-js est `.abortSignal(signal)` **chaînée sur le builder** (pas `{ signal }` en argument de `.rpc()`). Or le proxy paresseux de `supabase.ts` définit `rpc` comme une fonction `async` qui _retourne_ le builder PostgREST : la valeur de retour thenable est adoptée par la promesse `async`, donc la requête **s'exécute** et `await supabase.rpc(...)` renvoie `{data,error}`, pas le builder → impossible de chaîner `.abortSignal()` en l'état. **Correctif recommandé** : le pattern React officiel du drapeau `ignore` au cleanup (`let ignore=false; …; return () => { ignore = true }`, cf. react.dev « Fetching data »). Si une vraie annulation réseau est souhaitée, refactorer le proxy pour exposer le builder puis utiliser `.abortSignal(controller.signal)`.
- **`src/styles/app.css:632-658`** — 3 `backdrop-filter: blur(10px)` (`.nav-top-pill`, `.nav-bottom-strip`, bandeau) superposés à une carte qui se repaint en continu → recompositing GPU permanent sur mobile bas de gamme (la cible). Réduire le rayon (4-6px), limiter la surface, ou fond semi-opaque pendant la navigation.
- **`src/App.tsx` (30-150+)** — composant racine surchargé : 10+ `useEffect`, ~8 refs, machine à 6 états et logique entrelacée (arrivée, orientation, centrage, vue initiale). Extraire vers `useReducer` et/ou sous-composants (`<NavigationStateContainer/>`, `<MapContainer/>`).
- **`src/hooks/useRouting.ts` (74-85, 150-165)** — race condition entre l'effet de trimming et l'effet de recalcul lors d'un déplacement rapide ; le throttle 3 s (`lastOffRouteRecalcRef`) est une rustine. Synchroniser via un state de recalc (idle/pending/success).
- **CSP livrée en `<meta>`** (`index.html:80-83`) — `frame-ancestors` **est ignoré** dans un `<meta http-equiv>` (confirmé MDN/OWASP) → l'anti-clickjacking repose uniquement sur `X-Frame-Options` du `.htaccess`. Servir la CSP via header `.htaccess` avec `frame-ancestors 'none'`.

### 🟡 Mineurs

- `index.html:77` — meta `Permissions-Policy` **inopérant** : aucune équivalence `<meta>` n'existe, seul l'en-tête HTTP est honoré (confirmé MDN). La valeur `geolocation=*` est trompeuse. Supprimer le meta, garder l'en-tête `.htaccess`.
- `src/lib/routing.ts:217` — clé ORS en query string (`?api_key=`) mise en cache par le SW (Tier 5, cache-key complète) → la clé persiste en clair dans Cache Storage. Restreindre la clé par domaine/référent (dashboard ORS) ou normaliser la cache-key.
- `src/sw.ts:57-68` — Tier 4 (cache Supabase) **inopérant** : `registerRoute` de Workbox ne matche que les GET par défaut (les RPC sont des POST), et l'API Cache **ne peut pas** stocker de POST (Workbox lève `attempt-to-cache-non-get-request`). _(corrigé après doc)_ → **supprimer** ce tier (pas de « conversion » possible) ; si un offline des données est requis, passer par `NetworkOnly` + Background Sync (sans mise en cache) et peser la persistance vs RLS.
- `vite.config.ts:29-33` — commentaire « Drop console.log and debugger in production » sans effet : aucun drop configuré, les `console.*` restent en prod. _(corrigé après doc)_ → en Vite 8 (Rolldown + minifieur Oxc), `esbuild.drop` n'existe plus. Utiliser :
  ```ts
  build: {
    rolldownOptions: { output: { minify: { compress: { dropConsole: true, dropDebugger: true } } } },
  }
  ```
  (gotcha migration : ne pas passer `drop: []` — utiliser `undefined` hors prod.) Alternative de repli : `build.minify: 'esbuild'` (déprécié) avec esbuild en devDep.
- `public/.htaccess:41` — `X-XSS-Protection "1; mode=block"` **déprécié** (filtre retiré des navigateurs, risques legacy) — confirmé MDN. Passer à `Header set X-XSS-Protection "0"` et s'appuyer sur la CSP.
- `index.html:82` — CSP `script-src 'self' blob:` : `blob:` probablement inutile (les workers MapLibre sont couverts par `worker-src 'self' blob:`), affaiblit la surface. Vérifier au runtime puis retirer.
- `src/styles/app.css:999-1009` — `@keyframes dest-pulse-ring` anime `box-shadow` (non compositable GPU) en boucle → repaint continu pendant toute la navigation. Passer à un pseudo-élément animé en `transform: scale()` + `opacity`.
- `src/hooks/useRouting.ts:259-276` — `flattenCoordinates` + `projectPointOnLine` (O(n)) calculés 2×/tick GPS (dérivation off-route + effet trim). Mémoïser sur `[originLng, originLat, fullRoute]`.
- `src/components/NavigationOverlay.tsx:52-80` — mode « ligne directe » (fallback) sans indicateur visuel de navigation dégradée.
- `src/components/GpsPermissionOverlay.tsx` / `src/hooks/useDeviceOrientation.ts` — reset d'erreur tardif et `setTimeout` interne (300 ms) non nettoyé au démontage.

## 6. Références officielles consultées (validation des correctifs)

- **supabase-js** — annulation via `.abortSignal(signal)` chaînée sur le query/rpc builder (source : tests officiels `postgrest-js`, `from().select().abortSignal(ac.signal)`). Confirme que `{ signal }` en argument de `.rpc()` n'existe pas.
- **React** (react.dev, « Synchronizing with Effects » / « Fetching data ») — pattern de nettoyage par drapeau `ignore` pour les fetch dans un effet.
- **MapLibre GL JS** — `GeolocateControlOptions` : `positionOptions` par défaut `{ enableHighAccuracy:false, maximumAge:0, timeout:6000 }` (source : `src/ui/control/geolocate_control.ts`). `positionOptions` est un `PositionOptions` standard passé à l'API Geolocation.
- **Vite** (guide de migration v7→v8) — `esbuild.drop` → `build.rolldownOptions.output.minify.compress.drop*` ; minifieur Oxc par défaut ; `dropConsole` équivalent à `drop:['console']` (Oxc « Dead Code Elimination »).
- **Workbox** (Chrome for Developers, `workbox-routing`) — `registerRoute` par défaut GET uniquement ; POST routable via 3ᵉ paramètre mais **non cachable** (Cache API = GET), d'où `NetworkOnly` + Background Sync.
- **MDN / OWASP** — `frame-ancestors` ignoré en `<meta>` (header requis) ; `Permissions-Policy` sans équivalent `<meta>` (header requis) ; `X-XSS-Protection` déprécié, recommandé à `0` + CSP.
- **web.dev / MDN (rendu)** — seules `transform` et `opacity` sont compositées ; `box-shadow` et `backdrop-filter` déclenchent paint/composite coûteux, à éviter sur éléments animés en continu.
